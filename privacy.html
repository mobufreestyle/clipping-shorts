Privacy policy

Last updated: 21 October 2026

Clipping Shorts is a private tool. Only its owner uses it, for the owner's own YouTube channel.

What data the tool uses

  • It uploads videos to the owner's channel and sets their title, description and publish time.
  • It reads view counts of these videos.

What the tool does not do

  • It does not collect data from other people.
  • It does not sell or share data with third parties.

Storage

The access token stays on the owner's computer. You can revoke access at any time on Google's security settings page.

YouTube API Services

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
